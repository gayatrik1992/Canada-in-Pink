# Canada-in-Pink
This interactive map displays approximately 29,780 populated-place records across Canada as pink dots, highlighting the geographic distribution of named settlements and localities. Created in QGIS using Natural Resources Canada’s Canadian Geographical Names Database, it groups 80 detailed feature types into five marker-size classes, ranging from 0.8 to 2.5 mm. Dot size distinguishes grouped place types—not population—and the groupings are cartographic choices rather than an official settlement hierarchy.

Concept inspired by unmap’s Day 1: Points for the #30DayMapChallenge 2026. Data source: Natural Resources Canada, Canadian Geographical Names Database.
